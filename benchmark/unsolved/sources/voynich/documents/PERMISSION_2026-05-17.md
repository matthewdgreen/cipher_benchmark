# Permission Note — René Zandbergen (2026-05-17)

This file records the permission status for use of the Voynich transliteration
files hosted at `voynich.nu` in this benchmark.

## Source

- From: `info@voynich.nu` (René Zandbergen)
- To: Matthew Green
- Date: 2026-05-17
- Context: permission request to include Voynich transcriptions in the
  `cipher_benchmark`

## Substantive permission

René Zandbergen wrote that we are:

> very welcome to use any or all of the transliteration files I have made
> available at my web site.

## Methodological caveat

He also cautioned that, for automated processing:

> the transliteration alphabet is a relatively arbitrary choice

and that tools should ideally support not only reassignment of the letters but
also alternative grouping of glyphs into assumed characters.

## Benchmark interpretation

This benchmark therefore treats the ZL3b-derived Voynich records as
redistributable with attribution, while explicitly documenting that the present
transcription is only one reproducible transliteration view and not a final
Voynich glyph ontology.
