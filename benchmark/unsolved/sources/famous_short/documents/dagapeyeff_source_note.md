# D'Agapeyeff source note

The D'Agapeyeff cipher is an unsolved challenge cipher printed in the first edition of Alexander D'Agapeyeff's 1939 book *Codes and Ciphers*. It was omitted from later editions. Public summaries report that D'Agapeyeff later forgot how he had encrypted it, and modern discussion often treats an encoding or transcription error as plausible.

The benchmark target preserves the public five-digit grouping as the canonical transcription. A separate AZdecrypt-derived two-digit-pair file is stored as a hypothesis view, not as ground truth. AZdecrypt also bundles the Polybius worked example from *Codes and Ciphers*; this is stored only as related method context because it is not the target ciphertext.
